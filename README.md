# Shapes Around Us (Grade 4, Chapter 1)

A guided shape-skills ILM: a story hook, then hands-on missions (2D vs 3D, block subtraction,
triangle splitting, sequencing) and four master stations (painted cube, pyramid crate, cake slicer,
tunnel box). Tara the guide reads every instruction aloud. Fixed 1920 x 1080 stage.

Open `index.html`, or use the live page from GitHub Pages.
